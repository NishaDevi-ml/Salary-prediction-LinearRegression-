# Salary-prediction-LinearRegression-
## Overview

This project predicts salary based on years of experience using Linear Regression.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Dataset

The dataset contains:

- YearsExperience
- Salary

## Workflow

1. Data Loading
2. Data Visualization
3. Train-Test Split
4. Model Training
5. Prediction
6. Evaluation

## Machine Learning Algorithm

Linear Regression

## Results

The model learns the relationship between years of experience and salary and predicts salary for new experience values.
